What Artemis is

An assistant you talk to — and a model built from scratch.

Today, Artemis is a chat assistant at /chat with saved conversations, web tools and a code workspace. Underneath, Cutline Industries is training Artemis's own mixture-of-experts model from random initialization — not a fine-tune, not a wrapper. Until that model is ready, Chat is answered by a bootstrap model, and the app says so.

Where
In your browser at /chat, on desktop and mobile
Your data
Conversations are saved to your account and are not automatically used to train Artemis
Design rule
Artemis's own model never calls an outside AI model in its reasoning

Build with it

For developers, Artemis also comes as a terminal coding agent and an API. Both are available by request.

  • Artemis CLI — finds context in a repository with glob, grep and ranged file reads; no vector database. artemis serve runs a local API with OpenAPI docs.
  • Artemis API — streaming chat, an OpenAI-compatible chat completions endpoint and per-account memory, with server-side API keys.

How it works

One orchestrator, ten specialists — and a status you can check.

  1. Artemis reads your requestThe orchestrator decides which specialist brains to involve and hands each a focused sub-task.
  2. Specialists do the workSaturn handles code, Neptune research, Uranus math, Mercury memory, Pluto system design, and so on.
  3. Venus audits itBefore Artemis answers, Venus checks the other brains' work for errors and unsupported claims.
  4. Artemis writes the answerOne reply, streamed back into your conversation and saved to your account.
